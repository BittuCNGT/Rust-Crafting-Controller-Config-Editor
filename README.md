# Rust-Crafting-Controller-Config-Editor
This is an ai generated editor for Crafting controller plugin for rust game server which has a GUI and is just a webpage that anyone can just download and run

How to use
1. Download the file and open it.
2. Import the CraftingController.json
3. Edit the values for your liking.
4. download the edited json file.
5. Upload to your server plugin configs folder and reload the plugin.
